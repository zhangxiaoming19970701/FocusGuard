# V0.1 实现采用的产品决策

在需求尚未升级为 V1.0 冻结版的情况下，本仓库采用说明书中的推荐值：

- 连续超时默认进入全局休息，电话、来电、紧急呼叫和 System UI 保持可用。
- 管理员临时解除默认 15 分钟。
- 首版同时支持禁用时段与“仅在以下时段允许使用”。
- 忘记密码使用一次性生成的 8 位本机恢复码，不设置固定万能密码。
- 首版仅做本机本地管理，不建设远程家长端。
- 普通安装版不承诺绝对防卸载/强停/关闭权限；更强控制应独立采用 Device Owner/DPC。
- 默认详细事件保留 90 天、使用统计保留 365 天；CSV 导出后置。
- 默认连续上限 30 分钟、休息 20 分钟、会话合并间隔 10 秒、每日重置 00:00。
