# FocusGuard 真机验收计划

本计划对应功能说明书 AT-001 至 AT-023。GitHub CI 只能验证纯 Kotlin 规则和 APK 编译，不能替代真机系统行为测试。

## 设备矩阵

至少准备三台不同厂商设备，建议覆盖：

- Android 10–12：一台较旧设备
- Android 13–15：一台主流设备
- Android 16/17：一台新系统设备或模拟器加真机
- 至少包含一个后台管理严格的厂商系统

记录：厂商、型号、Android/API、系统版本、电池策略、是否允许自启动、是否开启 Usage Access。

## 核心技术验证门槛

1. 连续使用 2 分钟、休息 1 分钟，到时进入黑屏且倒计时正确。
2. 当前时间命中禁用时段，点击受管应用后 P95 目标在 1 秒内显示“当前无法使用”。
3. 黑屏密码输入不弹系统输入法，数字格稳定，不随软键盘跳动。
4. 上述三项在至少三台不同厂商真机通过，才进入可靠性完善。

## 功能用例

| ID | 操作 | 预期 |
|---|---|---|
| AT-001 | 全新安装，完成披露与权限向导 | 首页显示保护正常，不申请无关权限 |
| AT-002 | 保护正常时重启并解锁 | 无需打开主界面即可恢复监测 |
| AT-003 | 连续上限 2 分钟，休息 1 分钟 | 到时黑屏休息，倒计时准确 |
| AT-004 | 使用 90 秒，切桌面 5 秒后返回 | 仍为同一连续会话，约 30 秒后触发 |
| AT-005 | 离开超过合并间隔后返回 | 新连续会话，每日累计继续 |
| AT-006 | 每日额度 3 分钟，分两次使用 | 达到后再次打开被拦截 |
| AT-007 | 设置当前时间为禁用时段 | 1 秒目标内显示“当前无法使用” |
| AT-008 | 设置 22:00–07:00 | 23:00、06:30 阻断，08:00 允许 |
| AT-009 | 全局休息时切桌面和普通应用 | 持续重新显示休息页，电话白名单可用 |
| AT-010 | 休息未结束时重启 | 按原结束时间继续，不重新计满 |
| AT-011 | 使用中锁屏 60 秒 | 锁屏期间不计入使用 |
| AT-012 | 黑屏输入正确密码 | 不弹系统键盘，进入管理员操作 |
| AT-013 | 连续输错 5 次并旋转/重开 | 暂停 30 秒，不能绕过 |
| AT-014 | 临时解除 15 分钟 | 期间允许，到期自动恢复 |
| AT-015 | 手动关闭无障碍服务 | 首页/通知显示保护失效 |
| AT-016 | 休息时前调/后调系统时间 | 同一开机周期不能直接跳过，日志记录变化 |
| AT-017 | 全局休息时收到电话 | 可接听，结束后恢复休息 |
| AT-018 | 快速打开多个受限应用 | 无多个重叠拦截页或闪烁循环 |
| AT-019 | 横屏游戏超时 | 拦截页完整覆盖，文字不裁切 |
| AT-020 | 分屏/PiP | 按定义拦截，或在报告中明确机型限制 |
| AT-021 | adb/系统回收 FocusGuard 进程 | 重建后规则、统计、锁定一致 |
| AT-022 | 典型规则连续运行 72 小时 | 无崩溃、持续内存增长或漏检趋势 |
| AT-023 | 检查数据库、日志、诊断复制 | 无密码明文、聊天内容或键盘输入 |
| AT-024 | 当前应用命中禁用时段，锁屏后直接解锁回到该应用 | 不打开 FocusGuard，目标应用仍在 1 秒目标内被拦截 |
| AT-025 | 无障碍服务正常时熄屏隔夜 8–12 小时，早晨直接解锁 | 无需重新开权限，首页心跳正常，受限应用立即拦截 |
| AT-026 | 用 `adb shell am kill com.focusguard.app` 模拟可恢复的进程回收后解锁 | 系统自动重绑；若未重绑，健康检查发出持续告警且直达无障碍设置 |
| AT-027 | 权限仍显示开启但让服务心跳超过 25 分钟（测试构建可注入） | 健康检查判定服务失联，不把“权限已开”误报为保护正常 |

## 性能记录

- 受限应用进入到拦截页可交互延迟：至少采样 100 次，计算 P50/P95/最大值。
- 10 分钟连续使用计时误差：目标 ±2 秒。
- 24 小时空闲额外耗电：目标 ≤2%，必须记录测试手机、基线和测量方法。
- 每次解锁只允许有界恢复尝试，不得出现常驻秒级 UsageStats 或包名轮询。
- 72 小时内存：记录起始、24h、48h、72h PSS。
